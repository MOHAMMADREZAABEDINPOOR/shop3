# COMMERCE · PHP

فروشگاه PHP بدون فریم‌ورک با لایه کوچک MVC و روتر، راه‌اندازی SQLite، صفحات مشتری و مدیر و محتوای دوزبانه محصول.

[GitHub](https://github.com/MOHAMMADREZAABEDINPOOR/shop3) · [PIMX / Profile](https://github.com/MOHAMMADREZAABEDINPOOR) · [بنر ثابت](assets/readme/hero.png)

## امکانات

- کاتالوگ، دسته‌بندی، نظر و علاقه‌مندی
- سبد، تسویه، کوپن و پیگیری سفارش
- مدیریت محصول، سفارش و کاربر
- کنترل نشست، ابزار CSRF و محدودیت نرخ و فایل زبان

## پشته فنی

| ابزار | نسخه یا منبع |
|---|---|
| PHP | `8.1+ / PDO SQLite` |

## شروع کار

PHP 8.1 یا بالاتر، PDO SQLite و دسترسی نوشتن به database/ و public/uploads/؛ cURL و GD برای پردازش رسانه توصیه می‌شوند.

```bash
git clone https://github.com/MOHAMMADREZAABEDINPOOR/shop3.git
cd shop3

# Copy .env.example to .env and set APP_KEY
php -r "echo base64_encode(random_bytes(32)), PHP_EOL;"
php -S 127.0.0.1:8000 -t public public/router.php
```

## استفاده

نمونه را به .env کپی، APP_KEY تولید، PDO SQLite فعال و PHP را با public/router.php اجرا کنید. ساختار SQLite و داده نمونه در شروع ساخته می‌شود. ریشه وب‌سرور باید public/ باشد.

## ساختار پروژه

| مسیر | نقش |
|---|---|
| [`app/`](app/) | مسیرها یا کد برنامه |
| [`assets/`](assets/) | فایل برند، رسانه و README |
| [`database/`](database/) | ساختار و نمونه دیتابیس |

## فرمان‌ها و بررسی

فرمان آزمون خودکار در manifest تعریف نشده است. اجرای محلی و بررسی رفتار نمونه را انجام دهید.

## استقرار

فایل محیط واقعی، HTTPS، دیتابیس مستقل و میزبان مجاز تنظیم کنید. در PHP ریشه وب را public/ و در Django فایل استاتیک و WSGI/ASGI را تنظیم کنید. سرور توسعه برای میزبانی عمومی نیست.

## محدودیت‌ها

گذرواژه‌های نمونه فقط برای نمایش محلی هستند. تنظیم MySQL و ابزار خروجی MongoDB موجود است ولی مسیر اصلی راهنما SQLite است. فایل دیتابیس منتشر نشود و APP_DEBUG روی هاست خاموش باشد.

## رفع مشکل

- پکیج غایب: وابستگی را با مدیر پکیج پروژه نصب کنید.
- خطای API یا شبکه: آدرس، سرویس و اتصال میزبانی را بررسی کنید.
- فایل قدیمی: در صورت وجود اسکریپت ساخت، build و کش مرورگر را تازه کنید.

## مشارکت

برای تغییر، شاخه مستقل بسازید، رفتار فعلی را بررسی کنید و توضیح روشن همراه تغییر بفرستید. اطلاعات خصوصی، خروجی build و دیتابیس محلی را commit نکنید.

## مجوز

فایل مجوز در این نسخه موجود نیست. نمایش عمومی کد به‌تنهایی مجوز استفاده مجدد نیست؛ برای شرایط استفاده با مالک مخزن هماهنگ کنید.
